# DesignOS

AI-Native Document Operating System

## Vision

DesignOS is an AI-first platform that generates professional documents, presentations, reports, PDFs, and websites using a **Lean 2-Stage AI Pipeline**:
1. **Content Planning**: Deep semantic understanding and structuring of the user's ideas.
2. **Direct Visual Rendering**: High-quality, premium HTML & Tailwind CSS generated directly by the LLM.

By communicating with AI in its natural language (HTML/CSS), we eliminate unnecessary complexity and deliver stunning, reliable results.

## Tech Stack

- Next.js (Frontend)
- FastAPI (Backend)
- Gemini API (LLM Engine)
- Tailwind CSS (Styling)
- shadcn/ui (Components)
